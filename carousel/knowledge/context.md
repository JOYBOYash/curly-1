# Context system — one context per topic/angle (not global)

Contexts are **topic-scoped**. Every time the user asks for a carousel, decode
the brief first (copywriting.md §2) and write the result as the run's own
context file: `carousel/runs/<run-folder>/context.md`. This is step one of
every run — before any copy exists.

A hook, headline or CTA for topic A must call out **topic A's audience** in
**topic A's language**. Never reuse topic A's angle, vocabulary or audience
for topic B, and never blend a run's context into global copy rules. What IS
global is only the mechanism below.

## Per-topic context file (create at init, edit plan copy from it)

Write all five sections — short, concrete, no generalities:

1. **Topic & angle** — the one thing being communicated + the chosen angle
   (mistake / myth correction / mechanism / transformation / comparison …).
   One sentence on why THIS angle beats generic coverage of the topic.
2. **Audience of this topic** — who the ONE intended reader is (role, moment,
   awareness level), what they want, fear, believe and have tried.
3. **Call-out & targeting** — the exact call-out to open the set (identity or
   moment), plus the audience's own phrases to use verbatim in hooks/subtitles.
4. **Ban list (anti-neutralization)** — the generic/vague framings that must
   NOT appear (e.g. "pro tips", "5 things productive people do", "level up").
   If a slide could post unchanged from any niche, rewrite until the target
   reader of THIS topic feels named in line one.
5. **Arc + facts** — the slide arc (hook → proof → mechanism → recognition →
   counterintuitive fix → CTA) adapted to this angle, and the verified facts /
   sources available for it.

## Global rules that apply to every topic (unchanged)

- Every hook = call-out + value condition (copywriting.md §5).
- Specific beats vague: anchor to the topic's real slices (a moment, a place,
  a task type), never "everyone" / "your day" placeholders.
- Numbers inside plain sentences, never notation (00-how-to-run.md hard rule).
- Facts verified from primary sources, cited in the tiny gray note.

## Context library

Topic contexts from past runs live in each run folder. Reuse one only when the
user re-opens the SAME topic lane; start fresh for a new topic.
A first stored example: `runs/20261104-131331-how-to-stay-productive-at-work/context.md`.
